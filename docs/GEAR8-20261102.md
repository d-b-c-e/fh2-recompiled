# FH2 explicit eighth H-pattern binding: offline consumer check

The SDK parser now recognizes `GEAR8` in wheel_buttons. Existing GEAR1..7,
REVERSE, neutral, gamepad buttons and defaults are unchanged. This adds an
explicit binding; it does not measure shifter button numbers, change an owner
mapping, bypass focus/read guards, alter force output or add a gear to a car.

The gap was at the parser. TargetForName accepted onlyGEAR1..7 and silently
discardedGEAR8. SDLInputDriver already forwards binding.gear into raw thumb_rx.
FH2's generated sub_82D841A0 reader and sub_824972C0 sampler already map raw8
to request8, as the existing gear-refusal fixture establishes. No guest hook,
address or generated code was changed.

SDK source **e223de8d7aff090c0acc7a519582f35631e81b21** is retained in the
isolated SDK atwindows/.local/cvar-preserve/sdk, localvuro/gear8-20261102.
The parser, help/header/docs and existing unit expectation change; actual
transmission application and available gear counts remain outside this check.

## Reproduction

In an x64 VS developer shell, with the existing qualified generated source and
built SDK dependencies, run:

```powershell
python -I windows/tools/fh2_wheel_gear8_check.py --source-sdk <patched-sdk> --built-sdk <qualified-built-sdk> --generated <private-generated-directory> --cxx <clang++.exe> --out <fresh-project-output>
```

The runner reuses fh2_gear_refusal_check.py to emit the actual generated reader
and sampler fixture. It compiles the actual wheel_mapping.cpp, importing only
the unchanged production PadControlFromName from the qualified runtime DLL.
Parsed gates are placed in the synthetic cached pad state that the generated
guest routine reads. The SDK SDL driver assignment is source-verified; the
driver itself, device polling and capability acquisition are not executed.
The4GiB guest address range is reserved privately with only the fixture pages
committed. No game is launched, SDL initialized, GPU/device opened or owner file
accessed. All generated guest bytes/code and executables remain private.
